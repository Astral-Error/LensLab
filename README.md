# LensLab
A React + Vite web application for exploring camera lenses and their specifications.

# Dependencies:
- react-router-dom
- react-hot-toast

# To run the project on Windows:
1. Clone the repo using: **git clone https://github.com/Astral-Error/LensLab**
2. Navigate to the folder using CMD terminal
3. Install dependencies: **npm install**
4. Start the development server: **npm run dev**
5. Copy paste this link in your browser: **http://localhost:5173**
